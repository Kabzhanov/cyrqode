# Фирменный символ

`cyrqode-symbol.png` — символ технологии CYRQODE. PNG 1254×1254 с прозрачностью.

## Палитра

| Цвет | HEX | RGB | Где применяется |
|---|---|---|---|
| Фиолетовый | `#4800FF` | 72, 0, 255 | основной цвет знака |
| Тёмный сине-чёрный | `#04101F` | 4, 16, 31 | контрастные секторы |

Значения получены из самого файла, а не подобраны на глаз.

## Правила использования

- Символ — часть охраняемого бренда, см. [`../TRADEMARK.md`](../TRADEMARK.md).
  Совместимость с протоколом BUIP не даёт права ставить этот символ на свой
  продукт.
- Не менять пропорции, не поворачивать, не перекрашивать, не добавлять эффекты.
- Сохранять свободное поле вокруг знака не менее половины диаметра внутреннего
  кольца.
- На тёмном фоне использовать вариант с прозрачностью как есть; инверсных
  вариантов пока нет.

## Чего не хватает

**Векторного исходника.** Есть только растр. Для регистрации знака, печати на
упаковке, лазерной гравировки и штампов нужен SVG, AI или EPS — растр при
масштабировании рассыпается, а гравировка требует контуров, а не пикселей.
